# Fogle Invoice Studio

Free, local-first invoice maker for Fogle Unlimited. GitHub Pages hosts only the app code; invoice data is saved in each browser's localStorage.

## Features
- Client and business details
- Itemized invoices with quantity, rates, discounts, tax and totals
- Manual invoice status
- Print / Save as PDF using browser print dialog
- Save and reopen in same browser
- JSON export and import for backups
- PWA manifest and offline service worker

## Deployment
GitHub repository Settings > Pages > Deploy from branch > main > / (root). Visit https://fpkyn75zcb-prog.github.io/fogle-invoice-studio/ after publishing.

## Important
No account authentication, encryption, cloud sync, payment collection, or email sending. Avoid shared devices and export secure backups. GitHub Pages is public. Tax default is illustrative, not tax advice.
